# 0067: UniiChat's calls forbid tool use

Compaction calls send the chat's tools only so they share its cache; OpenCode's `generate` returns text alone, so when the model calls a tool anyway (the prompt says "Call no tools", but about one call in a hundred did on `openai/gpt-6-luna`) the answer comes back empty and the node falls back to its source clipped. OpenCode's `generate` hook has no tool-choice setting, so for calls that carry tools UniiChat rewrites its own throwaway session's HTTP request: `tool_choice: {"type":"none"}` on Anthropic Messages, `tool_choice: "none"` on OpenAI Responses and Chat Completions, `toolConfig.functionCallingConfig.mode: "NONE"` on Gemini. The tools stay in the request, so the cached prefix is unchanged; on Anthropic a different `tool_choice` than the chat's may cost the cached messages, but system and tools stay cached. Other APIs (Bedrock) go out unchanged. `/btw` lookups carry no tools and are untouched. When a call still returns no text, a warning names how the response ended and what it held, read from a copy of the response body.
