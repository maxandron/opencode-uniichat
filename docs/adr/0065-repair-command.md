# 0065: `/unii repair` rebuilds damaged summaries in place

The bug fixed by ADR-0064 saved greetings to the placeholder prompt and clipped copies as summaries, and merges summarized them. The log is intact, so the damage is only in the tree. On a session's first status request the plugin scans its tree files written since Oct 28, 2026 for untagged greetings about "UniiChat" and nodes equal to their clipped source, adds every merge above one, and shows the count. `/unii repair`, run by the user, moves those nodes to `repaired/<time>/tree.jsonl` and rebuilds them in the live chat, so no restart is needed; views keep their refs, which read "not summarized yet" until rebuilt. It runs only when no compaction is in flight, so no running call reads a node being dropped. It does not run by itself: detection is a heuristic, and rebuilding costs model calls and delays the next prompt.
