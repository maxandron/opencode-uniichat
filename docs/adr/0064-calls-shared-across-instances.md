# 0064: Calls in flight are shared across plugin instances, and fail closed

OpenCode may integrate the plugin several times in one server process (location boots, config reloads, an updated package), while a chat keeps the compactor of the instance that first opened it. Its calls can then be answered by another instance's `generate` hook, which used to not know them, so the model saw only the placeholder prompt and its greeting or empty reply was saved as memory. Keep the calls in flight and the throwaway sessions in one process-wide registry on `globalThis`, so any live instance applies any call, and name the call in its placeholder. A call whose request no hook applied fails instead of returning text, so the node is retried rather than filled with junk. Each instance logs when it integrates, opens a chat, and is disposed.
